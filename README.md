# 🎨 Muneeb Rehman — Sidewave-style Portfolio

**Scroll-driven creative portfolio — Next.js 16, React 19, Tailwind v4.**

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Visit%20Site-brightgreen)](https://muneeb-rehman-sidewave-style.vercel.app)
[![GitHub](https://img.shields.io/badge/GitHub-Repo-blue)](https://github.com/muneebrahmancmd/muneeb-rehman-sidewave-style)

All 16 live projects are shown as live, non-interactive iframe previews (click opens the real site).

## Features

- Scroll-driven Sidewave-style experience with a custom canvas wave scene
- 16 live project previews — TRIONN-style, Muna Haqi, Darw, Lusion, Portfolio 2.0 / 3.0 / 4.0 and more
- Origin, About, Services and Work sections with Muneeb's own details
- Fast, responsive Next.js 16 + React 19 + Tailwind v4 build

## Tech Stack

- Next.js 16, React 19, TypeScript
- Tailwind CSS v4
- Fontsource fonts (Anton, Space Grotesk, Space Mono)

## Run Locally

```bash
npm install
npm run dev      # or: npm run build && npm start
```

Edit text and project hosts in `src/lib/content.ts` (PORTFOLIO_ITEMS). Contact: muneebrahman500@gmail.com.

## Credits

Structure/CSS originate from the repo QalaLabs/clone-1, itself a clone of sidewave.it. The Unity WebGL scene and proxy were removed; `WaveScene.tsx` (own canvas animation) replaces them. Original fonts were replaced with free ones (Anton, Space Grotesk, Space Mono via fontsource). Third-party people, clients, awards and company details were removed.
